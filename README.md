# Blonde Bombshell Beauty

Website for **Krista Matthews** — bridal hair and makeup artistry in Edmonton,
Alberta.

Built with [Astro](https://astro.build). Static output, no server, no database.
Deployed on Vercel.

## Quick start

```bash
npm install
npm run dev
```

## Before it goes live

See **[SETUP.md](SETUP.md)**. The urgent item is step 3 — connecting the
booking form to Krista's inbox.

There's no custom domain yet, and none is needed. The site works out its own
web address from wherever Vercel serves it.

## What's worth adding next

See **[NEXT.md](NEXT.md)** — eight possible additions ranked by what they'd do

## Changing things

Prices, FAQ answers, gallery photos and contact details all live in
`src/content/` as plain files. Edit those rather than the page templates.

Once the CMS is set up, Krista can change the same things herself at
`/admin/` without touching any code.
